# Admin Affiliate rebuild — the reconciliation

**Session A, 2026-08-17.** Every element of the supplied reference
(`docs/design-refrence/Proovd-Affiliate-Admin.html`, a compiled Vite/React
bundle walked by extracting its application line — the registers `Vj`/`Gj`/
`Hg`/`Xj`, the 14 seed records, and every component from the directory at
byte 61131 to the Add flow at 135136) lands in exactly one of five buckets:

- **exists** — a record and a surface already hold it; the rebuild reads it.
- **extends** — the record exists; the read or the surface gains something.
- **new** — no record holds it; migration `0048` is the list, whole.
- **register change** — vocabulary or structure the shared register gains.
- **§1.8 refused** — the reference and the Spec disagree, and the Spec wins.

Sessions B and C extend this document rather than starting new ones. The
precedent for completeness is the previous bundle's 249-row traceability
matrix; this document trades rows for prose but the rule is the same — **an
element with no verdict is an element nobody decided about.**

The walk's mechanical replacements apply everywhere and are not repeated per
element: seed fixtures and `localStorage` become the real API; `prompt()`/
`confirm()` become `ConfirmDialog`; DOM-query navigation becomes React Router
with view state in the URL (DNA §5.12); the reference's own `<style>` becomes
`proovd.css` tokens; the `ME`-style hardcoded Admin becomes the Better Auth
session; client-derived statuses become the server's answer on the row;
`URL.createObjectURL` becomes the Phase 09a presign path; `Date.now()` ids
become database defaults.
